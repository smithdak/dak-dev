# Bundled fonts

These vendored fonts keep the site deterministic and independent of remote font
providers. Web pages load the official variable Space Grotesk WOFF2 from this
directory through `next/font/local`; image scripts retain the static TTFs for
downloadable SVGs and use pinned fontkit glyph outlines for raster PNG inputs.
Sharp receives path geometry with no text nodes or font definitions, so host
Pango and Fontconfig versions cannot alter the generated bytes.

The default social image and downloadable identity kit are static generated
assets. Regenerate all of them with `pnpm brand:generate`, or only the default
Open Graph image with `pnpm generate:og`; there is no dynamic image route or
runtime font fetch.
